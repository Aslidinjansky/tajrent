# TajRent

Платформа для аренды — объявления, арендодатели, чаты, верификация.

## Структура

- `public/` — фронтенд (HTML, CSS, JS)
- `server/` — бэкенд (Node.js + Express)
- `server/data/` — JSON-база данных

## Запуск

```bash
cd server
npm install express multer
node app.js
```

Откройте http://localhost:3000

## GitHub Pages (демо)

Для демо-версии без бэкенда используйте файлы из `public/` напрямую.
